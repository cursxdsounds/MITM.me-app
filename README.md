# MITM.me-app

Приложение-посредник для чата nekto.me, позволяющее подключить двух клиентов одновременно и общаться с собеседниками с обоих аккаунтов.

## Установка

### Windows

1. Скачайте zip-архив `publish` из раздела [Releases](https://github.com/cursxdsounds/MITM.me-app/releases).
2. Распакуйте архив в новую папку.
3. Запустите файл `MITM.me-app.exe`.

### Android

1. Скачайте APK-файл из раздела [Releases](https://github.com/cursxdsounds/MITM.me-app/releases) (если доступен).

2. Вам может понадобиться разрешить установку из неизвестных источников в настройках устройства:
   - **Настройки** → **Безопасность** → **Неизвестные источники** (или **Установка неизвестных приложений**).
3. Установите APK и запустите приложение.

> Если APK-сборка отсутствует в релизах, вы можете собрать её самостоятельно из исходников проекта или использовать приложение на ПК.

## Подготовка

Вам понадобятся **Token** и **UserAgent** для двух клиентов (двух разных аккаунтов nekto.me).

### Получение данных для каждого клиента

1. Откройте браузер и создайте **новое приватное окно**.
2. Перейдите в чат на [nekto.me](https://nekto.me).
3. Откройте DevTools (обычно `F12`) и перейдите во вкладку **Console**.
4. По очереди введите две команды:

   ```js
   userAgentSW
   ```

   ```js
   JSON.parse(localStorage.getItem("storage_v2"))["user"]["authToken"]
   ```

5. Результат первой команды — это ваш **UserAgent**, результат второй — **Token**.
6. Сохраните оба значения (без кавычек по краям).

Повторите те же действия во **втором приватном окне** для второго клиента.

> Возможно, вам потребуется пройти 5 капч для общения без их постоянного прохождения. Проверьте это заранее — иначе приложение не сможет корректно работать.

> Обязательно сохраните результаты обеих команд — они понадобятся при настройке.

## Настройка и использование

1. Откройте раздел **Settings** в приложении.
2. Введите **Token** и **UserAgent** для обоих клиентов.
3. Нажмите **Сохранить**.
4. Перейдите в раздел **Chat**.
5. Нажмите зелёную кнопку **CONNECT CLIENTS**. Когда она станет красной — клиенты подключены.
6. Нажмите кнопку **Search**.

Готово! Поиск собеседников запущен.

> Один из клиентов может найти собеседника раньше другого — это нормально. Вы можете начать общение сразу и подождать, пока второй клиент тоже найдёт собеседника.

### Как общаться

- Выберите нужный клиент в нижней части окна.
- Введите сообщение и отправьте его кнопкой рядом.

## Решение проблем

- Убедитесь, что **Token** и **UserAgent** введены правильно и без лишних символов.
- Проверьте, что оба аккаунта прошли необходимые капчи.
- Убедитесь, что вы используете актуальную версию приложения из раздела Releases.
- Если проблема сохраняется — откройте [Issue](https://github.com/cursxdsounds/MITM.me-app/issues) на GitHub, приложив описание проблемы и скриншоты из вкладки Logs.
